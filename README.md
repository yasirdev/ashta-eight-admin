## Service categories (no admin screen — edit in the DB)

The Home-screen "Service Categories" tiles (Somatic Programs, Face Architecture,
Neural Audio, Stress Recovery) are **not** managed in this admin app. They live in the
`content_categories` table and are edited by running the seed or updating the DB
directly — see `backend/prisma/seed.sql` (the `content_categories` block) for the four
slugs and how to point each tile at a `pillar`/`type`. The app only ever receives the
slug; a slug with no filter renders an empty list until configured. Adding a CRUD screen
here is deferred (R2 / on request) — it's a backend module and would go through the
architecture gate.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
